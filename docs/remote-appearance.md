# 可编辑遥控器外观

布局编辑器右侧提供常用按键与外观两个页签；外观页隐藏网格并在同一画布预览，底部操作位置不变。新布局默认黑色，已有手绘图保持原样，进入外观编辑后将当前草稿转为确定性生成外观。确认保存前不写入默认配置。

`layout.appearance`：`version: 1`；`color: black | silver | white`；`ratio` 是宽高比（0.18–0.5）；`radius` 是圆角半径/壳宽（0.04–0.45）；`top`、`bottom` 是留白/壳高（0.04–0.3、0.04–0.5，合计最多 0.7）。默认值为 0.28、0.18、0.08、0.18。

滑块和预览上的两条拖动边界控制相同的留白参数，边界支持方向键微调。按键区域按内部相对位置映射到剩余空间，圆角安全区可能进一步缩小按键区域，不占用人工留白。整机预览适配可用宽高，使用等比缩放。

外观参数随布局复制、JSON 保存以及机型默认配置覆盖保留。设备指纹、键码、按键功能与语音验证证明不因外观编辑而改变。公共库将同一对象放在 layout 资源的 geometry.appearance，不需要图片或 AI。

回归：tests/appearance.test.ts 验证格式、保存/覆盖/复制、留白边界、宽高比和三色确定性输出；既有 remote-artwork 测试验证边界和转义。
