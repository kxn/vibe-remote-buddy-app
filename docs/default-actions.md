# 默认按键

主页：任务视图；菜单：窗口选择器；返回：Backspace。
新配对、恢复默认及新适配的标准按键使用这些默认值。已有个人映射不自动改写。

BM_ACTION 的 65534 / 65535 分别保留给任务视图 / 窗口选择器，需运行上位机。
上位机分配个人动作使用 1–65533。已存在的同号个人动作优先且仍须授权。
内置动作只允许固定命令，不从型号资源执行任意程序；执行前仍核对设备身份与实际映射。
