# 弹层与布局检查（2026-09-22）

所有原生 dialog 和 aria-modal 弹层使用统一滚轮路由。背景锁定，外部滚轮交给顶层主要滚动区域；内部滚轮只能在该层内传递。Ctrl+滚轮保留系统缩放。关闭后恢复页面滚动。

修复：窄机型选择页强制双列；默认配置焦点边框裁切；机型库/默认配置操作区无法换行；矮窗口布局编辑器被压扁；日志初始焦点将页面拉到最底部。短窗口布局允许整体滚动并保留底部操作，日志块独立滚动。

验证使用真实 React 页面和模拟接收器边界，未连接硬件。`python tests/modal_layout_ui_check.py`（先在 5173 启动 Vite）覆盖 1000×780、720×640、400×620，DPR 1.5：首页、按键页及编辑、设置、机型库、默认配置/外观、关于、接收器信息、备份、诊断、搜索、机型选择、语音确认、布局/外观。验证水平溢出、操作区可达、遮罩滚轮和嵌套弹层隔离、动作 6 保存回读。图片保存在 build/host-ui，属于测试产物。
