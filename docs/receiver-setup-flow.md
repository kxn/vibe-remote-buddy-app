# 首次安装 / 恢复接收器：流程设计与实现

交互预览：`docs/mock/receiver-setup.html`。所有设备、规格和进度是模拟数据，不可据此宣称已具备 PSRAM 探测或自动刷机能力。

界面文案遵循 [UI 设计规范](ui-guidelines.md)。流程意图保留在本文档；预览中的场景控件与模拟说明使用紫色并标记「仅预览」，不属于成品。正常界面只保留状态、必要操作和破坏性后果。

## 入口与发现

- 未连接接收器且枚举到潜在 ESP 下载接口时，右上角显示「初始化接收器」。只是提示候选；串口名称、VID/PID 不能证明芯片是 S3 或能自动进入下载模式。USB-UART 芯片也可能连接其他 MCU。
- 设置 → 高级始终提供同名入口，进入同一对话框；无候选时等待插入并提供 BOOT 操作。自动枚举不能扫描所有串口发送复位或握手。
- 用户选中设备后「检查设备」才允许尝试复位；事先说明会暂时中断原程序，但不擦数据。多个设备不默认选择，更不能选完后因列表变化切换目标。

## 向导

### 第三版：按用户任务合并步骤

成品只显示「连接开发板 → 安装 → 完成」。不让用户选择“首次刷机”“恢复”“下载模式”等技术分支，由连接和检查结果决定下一步。

- 单个候选：显示一张设备卡及「连接这块开发板」，省去先选中再检查。该按钮明确授权暂时重启，绝不是发现候选就自动复位。
- 多个候选：才显示列表，要求明确选择；提示拔插辨认，列表保持稳定。用户找不到自己的设备时可进入 BOOT 帮助。
- 没有候选：先提示接 USB 数据线，持续被动枚举；「仍未找到？」展开 BOOT 拔插三步。连接失败复用同一帮助页，不再让用户学习下载模式。无需“我已操作”或反复手动刷新；实际检测到设备后自动推进。此前未选目标则展示新候选让用户连接，此前已选且能唯一确认同一设备才自动检查。无法唯一匹配不能擅自换板。
- 检查合并在连接操作内，芯片、安全和包兼容性仍完整验证。无安装包在打开向导时立即提示，不先重启设备。
- 确认页保留目标端口/标识、擦除后果、勾选和「清除并安装」；详细硬件规格与版本折叠。
- 写入失败提供「继续恢复」，复用 BOOT 帮助和检查，必须再次确认擦除。完成写入但没上线只等待重连，绝不自动重刷。
- 完成页直接提供「添加遥控器」，同时可选「完成」回首页。
- Mock 中的“模拟设备到达/上线”按钮为紫色「仅预览」控件，替代物理动作；成品使用设备到达事件，没有这些按钮。

以下描述底层必须保留的检查与约束，不代表需要逐项展示成 UI 步骤。

1. **选择设备**：端口、USB 名称和序列号后缀。建议通过拔插区分。没有设备时给出数据线/BOOT 检查。
2. **检查设备**：尝试进入 ROM 下载模式、确认芯片身份、安全状态、Flash 与目标板级规格、安装包完整性。自动进入失败才展开 BOOT + RESET 或 BOOT + 拔插说明；重枚举后重新匹配身份，多候选无法唯一关联时要求重新选择。
3. **确认安装**：展示芯片、设备标识、硬件规格、固件版本；明确全片擦除会丢失原固件及所有持久数据，无自动备份。未勾选确认前禁用「清除并安装」。切换设备或断连后确认失效；擦除前再次核对 ROM 芯片身份与清单。检测失败、保护开启、已知规格不兼容或无安装包均不能继续，不能提供强制覆盖绕过。
4. **安装与确认**：清除 → 写入完整镜像集 → 校验 → 重启 → 确认同一接收器版本及运行状态。擦写中禁用返回、关闭和重复操作；正式应用还需阻止托盘退出；系统强制终止及断电仍可能中断安装。异常断电不能阻止，应保存可恢复诊断。写入成功不等于安装完成。

取消选择/检查后的流程不擦除；检查可能已把设备留在 ROM 下载模式，正式实现应尝试复位回原程序并在无法复位时提示用户按 RESET。擦写开始后不提供取消。

## 边界

- 当前包支持 S3 / 8 或 16 MB Quad Flash，搭配 2 MB Quad 或 8 MB Octal PSRAM 两类目标。ROM/esptool 不能被假定能可靠识别所有外置 PSRAM；无法自动确认外置 PSRAM 时，要求用户核对板型并选择 2 MB Quad 或 8 MB Octal PSRAM 并勾选确认后继续（用户已批准）。芯片、8/16 MB Flash 和安全保护仍由程序检查；已知容量不兼容时禁止继续，人工确认不代表自动检测通过。
- 完整安装包必须包含 bootloader、分区表、初始 OTA 数据、应用及校验清单，不能拿当前 OTA receiver.bin 单独完成初始化。正常固件升级继续用现有双分区接口，不应走擦除流程。
- 公开应用不自动获得私有固件；未附带有效安装包时显示「没有可用的安装包」，不允许进入擦写。
- 写入失败：显示阶段、原始错误和恢复方法，重新检查同一设备并再次确认后才能重试。校验成功但重启超时：只提供重新检测，不自动擦除重刷。
- UI 普通用户只需读操作说明；芯片细节和原始错误放折叠详情。正式界面已接入独立烧录工具；仅 mock 使用模拟设备。

## 预览场景

正常自动安装、手动 BOOT、多个候选、无设备、非 S3、未知硬件规格、安全保护、无安装包、确认后拔出、写入中断、写入成功未重连。两个入口、破坏性确认与错误恢复均可点击验证。
