# 机型库与个人设置

应用接入公共资源格式2、板端catalog API2（固件0.10.0）。公共库固定文件名、稳定资源ID及独立revision；历史由Git保存。

## 数据边界

- `resources/catalog` 是随包发布的离线默认库，包含完整manifest及22份资源。在线更新只从 `kxn/vibe-remote-buddy-models` 固定commit下载，逐文件核对长度和SHA256，验证引用图后切换活动快照；保留当前与上一份目录。
- `resources/remotes` 和本地适配资源是独立私有层，公共下载不会写入这些文件。新适配保存完整采集证据，编译进接收器库。缺少完整Map的旧资源可保留已有绑定，不能据名字自动认定新设备。
- 接收器保存整个紧凑库；界面“接收器机型库→同步”替换整库。空库首次连接自动初始化，普通连接不反复上传。
- 四个绑定槽各自保存硬件定义、按钮名称、采用的默认快照、有效动作及覆盖位图。更新库、删除库内机型不会修改这些槽。
- 按钮编辑确认才保存，取消不生效；设置为相同默认值或禁用仍是显式覆盖。恢复默认移除覆盖。采用库中新默认是独立确认操作，保留个人覆盖，硬件不兼容时拒绝。
- 配置备份包含四槽快照。恢复要求接收器序列号、已绑定peer/model及当前revision匹配；逐槽原子提交。导入前撤销电脑动作授权，恢复失败也不会意外执行导入的命令。

## 编译与边界

`src/core/catalog.ts` 将公共引用图解析成运行模型视图和VRBC/1镜像，省略图片和编辑器几何。机型上限4096且同时受1.5MiB镜像上限限制，1024是规模回归基准。运行键编号由bNN或显式wire_id指定，voice为2；不按按钮数组顺序分配。

索引包含ID、完整Map和广播候选。名字只负责扫描准入；完整Map及required服务/PnP/报告信息决定身份。同名可以共存，歧义必须选择，不能按数组顺序判定。同一模型可列出多个已验证指纹。

`npm test` 验证四款实际数据、1024和4096边界、损坏CRC、重复ID、事务及覆盖；`node scripts/compile-catalog.mjs <输出文件>` 产生与固件解析器交叉验证的镜像。Windows生产构建嵌入前端，运行无需开发服务器。

联通与移动共享ICO协议和三列几何；169字节Map有差异，保留独立键表。RC003完整Map86字节，CRC32C 6bd7daad；旧款小米2717:32BA走HID/mSBC，同名不代表同款。库只保存default，个人override不进入公共PR。
