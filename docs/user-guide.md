# Vibe Remote Buddy 使用说明（Windows）

## 安装与连接

1. 运行 Windows 安装程序；或解压完整便携包，启动其中的 `Vibe Remote Buddy.exe`。便携版必须连同 `resources`、许可证和清单一起保留，不能只复制 EXE。
2. 用可传数据的 USB 线连接 Vibe Remote Buddy 接收器。接收器作为 USB 麦克风和键盘工作；管理应用通过其串口配置设备。
3. 在应用首页确认接收器已连接。日常使用语音及标准按键时，应用不必保持打开；自定义软件动作需要应用运行。

本程序只适用于运行 Buddy v1／RBP/3 管理协议的接收器，不适用于普通蓝牙适配器或旧版接收器固件。目前验证平台为 Windows x64。

## 添加和使用遥控器

1. 让遥控器靠近接收器并进入配对状态。在应用中打开“添加遥控器”，选择扫描到的设备，按界面提示完成配对。
2. 一个接收器最多绑定两只遥控器。已绑定设备上电后会自动重连；需要替换设备时，先解绑不再使用的遥控器。
3. 在遥控器详情中调整按键映射并保存。默认键盘和媒体键由接收器独立执行。语音键通过接收器的 USB 麦克风送入电脑；请在语音软件中选择该麦克风。
4. 自定义应用切换、窗口操作等软件动作需要应用在后台运行。导入备份后，请重新检查并保存这些动作的授权。

如果添加列表为空，确认遥控器处于配对状态并靠近接收器；扫描只显示近期发现且信号较强的设备。

## 初始化、更新和备份

- 新接收器可从“初始化接收器”进入向导。操作会清除板上原程序、配对和设置，确认板型和清除范围后再执行。应用自带的完整安装包与当前接收器硬件必须匹配。
- 已运行 Buddy 固件的接收器使用应用中的固件更新入口。普通更新会保留配置，不要用首次初始化代替更新。
- 在设置中导出本机配置，可在迁移或维护前留存。备份可能含本机应用路径和自定义动作，请自行妥善保管。
- “设置 → 关于”显示应用版本；接收器固件和机型库有独立版本。发行包根目录的 `build-info.json` 记录本次组合及文件校验值。

## 故障排查

- 接收器未连接：检查 USB 数据线和系统设备枚举，重新插拔后在应用中重试。
- 遥控器无响应：检查电池、距离和接收器上的绑定状态；可在应用中查看连接状态。
- 语音无输入：确认系统和语音软件选择接收器 USB 麦克风，再检查语音键映射。
- 需要协助排查时，记录界面显示的错误提示、应用版本和接收器版本。配置备份可能含设备身份和本机信息，分享前请检查内容。
